# Синтетический каталог для тестов

> Source: `synthetic-catalog.pdf`

## Page 1

Это искусственный пример для проверки поиска, а не исторический источник. В тестовом каталоге встречаются имена Мономах и Мономаха, название «Слово о полку Игореве» и выражение «Повесть временных лет». Эти слова проверяют только поиск и расширение запроса по словарю вариантов названий.

## Page 2

Фрагмент документа содержит номер версии и номер страницы. При обновлении документа старый фрагмент становится недоступным. Результат поиска содержит текст, но не является доказательством правильности ответа. Семантические векторы в этом примере не используются.
